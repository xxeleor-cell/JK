# JK — сайт-визитка врача-психиатра, психотерапевта

Одностраничный сайт частного специалиста: статический HTML/CSS/JS без сборки и зависимостей.
Все неподтверждённые сведения — **PLACEHOLDER**: в разметке они обёрнуты в `<span class="ph">…</span>`
и подсвечены на странице, пока у `<html>` стоит атрибут `data-placeholders="show"`.

## Структура

```
index.html                    главная (все 11 блоков)
privacy.html                  политика обработки персональных данных (шаблон)
consent.html                  согласие на обработку ПД (шаблон, отдельный документ)
404.html                      страница «не найдено»
css/styles.css                дизайн-система: токены → компоненты → секции → адаптив
js/main.js                    меню, подсветка разделов, анимации, копирование шаблона, просмотр документов
assets/img/                   фото-заглушка, OG-картинка, иконки
assets/docs/                  сканы дипломов и сертификатов (пусто)
favicon.svg, site.webmanifest
robots.txt, sitemap.xml
structured-data.template.json шаблон schema.org (не подключён до подтверждения данных)
```

Блоки главной: первый экран → О специалисте → С чем обратиться (+ «Если сомневаетесь» и разница психиатр/психотерапевт/психолог)
→ Форматы → Как проходит приём → Подход → Образование → Стоимость → Вопросы → Запись → Подвал с юридическими сведениями.

## Запуск локально

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080. Сборка не нужна; сайт работает и с отключённым JavaScript.

## Публикация

Подходит любой статический хостинг. Загрузите содержимое репозитория в корень сайта.

- **GitHub Pages:** Settings → Pages → Deploy from branch → `main`, папка `/ (root)`.
- **Netlify / Vercel / Cloudflare Pages:** импорт репозитория, build command пустой, publish directory — корень.
- **Свой сервер (nginx):** скопируйте файлы в `root`; добавьте `error_page 404 /404.html;`, включите gzip/brotli и HTTPS.

> Если сайт обрабатывает данные пациентов из РФ, учитывайте требование о локализации ПД (ст. 18 ч. 5 152-ФЗ):
> на самом сайте форм нет, но хостинг в РФ упрощает соответствие.

## Чек-лист перед запуском

Найти все места для заполнения:

```bash
grep -rn 'class="ph"\|PLACEHOLDER\|example.com' --include=*.html --include=*.txt --include=*.xml --include=*.webmanifest .
```

1. **Имя, специализация, город** — `<title>`, `description`, Open Graph, шапка, первый экран, подвал.
2. **Домен** — замените `https://example.com` в `index.html`, `privacy.html`, `consent.html`, `robots.txt`, `sitemap.xml`.
3. **Фото** — см. ниже. Перегенерируйте `assets/img/og-image.png` (1200×630) с реальным именем.
4. **Биография, образование, аккредитация, опыт, методы** — только подтверждённые документами сведения.
5. **Направления работы** — оставьте только те, что врач подтвердит.
6. **Форматы и цены** — длительность, стоимость, платформа онлайн-приёма, условия отмены, дата актуальности цен.
7. **Контакты** — Telegram (`https://t.me/USERNAME`), WhatsApp (`https://wa.me/7XXXXXXXXXX`), телефон (`tel:+7…`), почта; ссылка на карту.
   Неиспользуемые каналы удалите целиком (`<li>…</li>`).
8. **Юридические сведения** в подвале, политика и согласие — заполнить и проверить у юриста.
9. **Региональный телефон доверия** в блоке «Если нужна срочная помощь».
10. Удалите плашку `<div class="ph-banner">` и атрибут `data-placeholders="show"` у `<html>` во всех страницах.
11. После публикации — добавьте сайт в Яндекс Вебмастер и Google Search Console, отправьте `sitemap.xml`.

### Замена фотографии

Рекомендуется спокойный портрет в естественном свете, вертикальный кадр 4:5, без халата «для стока».
Подготовьте 640 и 960 px по ширине в AVIF и WebP (например, через [Squoosh](https://squoosh.app)), положите в `assets/img/`
и в `index.html` раскомментируйте строки `<source>`, а в `<img>` укажите JPG-версию:

```html
<img src="assets/img/portrait-960.jpg" width="960" height="1200" alt="Имя Фамилия, врач-психиатр, психотерапевт" …>
```

Обновите путь в `<link rel="preload" as="image">` в `<head>`.

### Добавление документов

Скопируйте карточку `<li class="doc">` в разделе «Образование и квалификация». Для просмотра скана сделайте её ссылкой
с атрибутом `data-doc` (пример — в комментарии в `index.html`); скан положите в `assets/docs/` (WebP/JPG ≈1600 px по ширине).
Скан открывается в модальном окне, без перехода со страницы. Рекомендуем скрыть на сканах номера бланков и личные данные.

### Шрифты

Сейчас Cormorant Garamond и Manrope загружаются с Google Fonts — при этом IP посетителя передаётся Google.
Для полного соответствия 152-ФЗ скачайте WOFF2-файлы (например, через google-webfonts-helper), положите в `assets/fonts/`,
подключите через `@font-face` в начале `css/styles.css` и удалите `<link>` на fonts.googleapis.com во всех страницах.
После этого удалите соответствующий абзац в `privacy.html`.

## Правовые моменты (РФ) — что проверить с юристом

Сайт подготовлен с расчётом на российскую юрисдикцию; при другой юрисдикции требования нужно пересмотреть.

- **Лицензия на медицинскую деятельность** (99-ФЗ, 323-ФЗ): частный приём возможен только при наличии лицензии у ИП или организации.
  Номер лицензии публикуется в подвале; ссылка на реестр Росздравнадзора уже есть.
- **Правила оказания платных медицинских услуг** (ПП РФ № 736 от 11.05.2023): на сайте исполнителя должны быть сведения об
  исполнителе (наименование, ОГРН, адрес, лицензия), перечень услуг с ценами, сведения о медработниках (образование,
  квалификация, аккредитация), режим работы, контакты контролирующих органов. Структура для этого уже есть.
- **Персональные данные** (152-ФЗ): уведомление Роскомнадзора об обработке ПД; политика обработки опубликована на сайте;
  согласие — отдельным документом. Сведения о здоровье — специальная категория: согласие на их обработку берётся письменно на приёме.
- **Реклама медицинских услуг** (38-ФЗ, ст. 24): в подвале размещено предупреждение о противопоказаниях. Не добавляйте отзывы,
  обещания результата, сравнения с другими врачами.
- **Врачебная тайна** (ст. 13 323-ФЗ) — ответ в FAQ сформулирован общо; врачу стоит его вычитать.

## Технические решения

- **Без формы записи.** Бэкенда нет, а форма, которая только имитирует отправку, вводит в заблуждение и собирает лишние данные.
  Запись идёт через реальные каналы (мессенджер, телефон, почта); есть кнопка копирования нейтрального шаблона сообщения без сведений о здоровье.
  Если позже понадобится форма — подключайте её только к реальному серверу с HTTPS, хранением в РФ, чекбоксом согласия и без поля «симптомы».
- **Без аналитики и трекеров.** Если подключите Яндекс Метрику — без Вебвизора и с баннером согласия на cookie.
- **Доступность:** семантическая разметка, skip-link, фокус-стили, `aria-expanded` и `inert` в мобильном меню, Esc закрывает меню и диалог,
  нативные `<details>` для FAQ, учёт `prefers-reduced-motion`, контраст текста не ниже AA.
- **Производительность:** ~60 КБ HTML + 38 КБ CSS + 9 КБ JS без сжатия, ноль библиотек, SVG-заглушка, `width/height` у изображений против сдвигов вёрстки.
- **Структурированные данные** не подключены намеренно: шаблон в `structured-data.template.json` — вставлять только после подтверждения сведений.
